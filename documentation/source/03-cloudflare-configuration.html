What the DNS picture means

  • No email is configured. There is no MX record and no SPF record, yet a DMARC record with p=quarantine exists. Any mail claiming to be from the domain has no SPF pass path and will be quarantined; this is harmless for the website but inconsistent if email is ever added.
  • No DNSSEC. The zone is not signed, so there is no DS record. Enabling DNSSEC is a one-click operation in the dashboard but requires care if the domain's registrar is changed later.
  • No CAA pinning. Certificate issuance is not restricted to an authority. Cloudflare currently issues through Google Trust Services (WE1).
  • The registrar's nameservers are no longer authoritative. The resolver's authority section points at Cloudflare, which is expected for an active zone.

Action for the owner: remove the stray secret. The fifth secret's name is itself a Turnstile-style key. It is not referenced by worker/env.ts or any other file. Keeping it costs nothing but widens the credential surface. After confirming no external tool depends on it, delete it in the dashboard under Worker → Settings → Variables and Secrets.

Rotation

  • ADMIN_PASSWORD_HASH — regenerate offline with the documented script, then replace the secret; existing sessions remain valid until the cookie expires (12 h) or SESSION_SECRET is rotated.
  • SESSION_SECRET — rotating it invalidates every admin session immediately. Use 32 random bytes, base64-encoded.
  • GITHUB_TOKEN — fine-grained, repository-scoped, expiring. Rotate in GitHub and Cloudflare together.
  • TURNSTILE_SECRET — rotate in the Turnstile dashboard and update the Worker secret in the same sitting.

R2, analytics and Pages

R2 object storage

R2 is not enabled on the account. wrangler r2 bucket list fails with Cloudflare error 10042 ("Please enable R2 through the Cloudflare Dashboard"). The MEDIA binding is commented out of wrangler.jsonc; /media/* and media uploads return 503, and the admin UI hides the upload control.

Enabling R2 would require: creating the bucket, uncommenting the binding, redeploying, and re-enabling the upload path in the admin UI. The resume page already points at the repository-hosted PDF so it does not depend on R2.

Cloudflare Web Analytics

The CSP was updated in commit 8c9ea09 to allow static.cloudflareinsights.com and cloudflareinsights.com. However, fetching the production HTML on 31 October 2026 returned no beacon script, including on a cache-bypassing request. The dashboard's Web Analytics state could not be re-read with the available token.

Unconfirmed Whether visits are being recorded. Check the Web Analytics dashboard for a non-zero visit count, or add the JavaScript snippet manually if the automatic injection is off.
